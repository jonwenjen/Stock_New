## 2. 回答別隊問我們的問題
- **視覺 Q1（整卡做成 `<a>`，還是只有標題可點）：** 只讓標題可點，因為 `<a>` 裡不能再放星號按鈕。做法：
  - 股名放進 `h3 > a.pick-link`，用 `::after{inset:0}` 讓整張卡可點。
  - 星號是獨立的 `<button aria-pressed>`，加 `z-index:1`。
  - 焦點樣式：`.pick:has(.pick-link:focus-visible){outline:2px solid var(--accent);outline-offset:2px}`。
  - hover 只改邊框。
- **視覺 Q3（法人買賣超用紅綠）：** 同意。金額與張數屬於實際成交，但一定要帶 ±，而且只用在數字上、不做底色。名次標籤，以及議員與 13F 的「買進／賣出」（延遲揭露）改成中性加文字。
- **IA Q3：**
  1. **地標：** 不新增。把現有的 `<nav id="groups" aria-label="主要分類">` 在 560 px 以下用 CSS 改成底部列，DOM 不動，仍然只有兩個地標，Tab 順序也不變。
  2. **`inert`：** Chrome／Edge 102、Safari 15.5、Firefox 112 起都支援。不支援的舊瀏覽器只是退回現況，Esc 與焦點還原照常可用。
  3. **`--line` 1.30:1：** 違反 1.4.11。輸入框底色和面板相同，外框是唯一能看出範圍的線索，改用 `--line-strong`。

## 3. 衝突與折衷

### 3.1 共用色票：以視覺隊第 4 節為基底
**接受：**
- `--rise／--fall`：#cc3924／#007d68（深 #ef6447／#2fb3a3）。
- `--ink-3` #676f7d、`--warn` #986300 與 `--warn-soft` #fdf3dc、`--surface-2` #f7f8fa、`--line-strong` #848d9b／#626c7c。
- 紫色明度階的風險色，以及 `--rk-ink`、`--rk-on`、`--rk-line`。
- 證據等級用外框、MA 三色、刪除漲跌 soft 底、保留 `--up/--down` 的間接層。

**撤回：** a11y-1 我們自己的色值（#c62f2f、#08775a、#636b78、#875800、#7f8998 等），以及 `--on-accent`。

**修正：**
1. 風險條各段之間留 1 px `--surface` 間隙，下方加「低／中／高／極高」，標記保留 `box-shadow:0 0 0 2px var(--surface-2)`。
2. 官方旗標用 visual-3 的反白印章，否決 IA P-2 的 rk2 底色。
3. accent 不做實心填色（rk3 對 accent 在綠色盲下 ΔE 只有 1.0）。我們撤回 a11y-6 的實心分段按鈕，改成 `.seg button[aria-pressed="true"]{background:var(--surface);color:var(--ink);box-shadow:inset 0 0 0 2px var(--accent)}`，外框對 surface-2 為 6.43／6.74。
4. K 棒預設空心陽線；MA60 加 `lineStyle:3`，MA120 照 visual-6 用虛線。
5. 證據等級不用實心底，避免和官方旗標撞型。
6. 底部導覽字級用 13 px（依 visual-7），不用 12 px。
7. visual-9 要和換色同時上線。

### 3.2 底部導覽列（ia-1）
- **焦點不能被遮住（2.4.11）：** `html{scroll-padding-block:calc(var(--mast-h) + 8px) calc(56px + env(safe-area-inset-bottom))}`。
- **輸入時讓位：** `body:has(input:focus, select:focus) #groups{display:none}`，免得蓋住軟體鍵盤上方的輸入框。
- **名稱一致（2.5.3）：** 短標籤都是全名的一部分，即使加上全名的 `aria-label` 仍然符合。
- 每個鍵高 ≥ 48 px，`aria-current="page"` 沿用現有寫法。

### 3.3 `inert`
抽屜開啟時，對 `body > header, main, footer` 設 `inert`（底部列在 header 內，會一起被鎖住）；關閉時解除並還原焦點。這樣不必自己寫 Tab 循環。改用原生 `<dialog>` 也可以，瀏覽器支援範圍相同。

### 3.4 固定首欄與螢幕閱讀器
- `position:sticky` 只影響畫面，讀屏依 DOM 朗讀。對讀屏來說，固定首欄的等價做法是把股名格改成 `<th scope="row">`，橫向移動時讀屏會報出股名。
- 橫捲時，焦點格可能被固定欄蓋住：設 `.tbl-wrap{scroll-padding-inline-start:<首欄寬>}`；固定欄內的連結用 `outline-offset:-2px`，避免焦點框被裁掉。
- 清單模式不要對 `tr` 設 `display:block`（Safari／VoiceOver 會失去表格語意），改成另外產生 `<ul>`。

### 3.5 精選頁的順序（視覺 Q2）
手機上組合風險加預算共 1,684 px，壓縮後仍超過一屏。建議採 IA 的順序，卡片在前，但卡片上方保留一行誠實摘要，例如「β 0.68・一個月 95% 虧損界線 −12%・部位預算 ▸」。
