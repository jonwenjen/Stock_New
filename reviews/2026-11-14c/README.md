小差異的處理：
- 紅色：視覺隊第二輪改用 #c62f2f，另兩隊採 #cc3924。採用 #cc3924，因為它在紅綠色盲下和綠色的差距較大（ΔE 24.2，對 19.0）。
- 琥珀：採多數的 #986300，對 warn-soft 為 4.62:1。
- 淺色 `--ink-3` 與 `--line-strong`：採 IA 的修正值（#636b78、#7f8998），對比餘裕較大。

## 元件規則

1. 紅綠只表示價格與實際成交，例如漲跌幅、K 棒、法人買賣超的張數或金額，而且一定帶 ± 或 ▲▼。分數、評等、預測、+1σ、加減碼標籤、名次變化與「資料來源成功」一律用墨色，方向靠 ▲▲／▲／■／▼／▼▼ 與 + − 表示。
2. 形狀分工：pill 表示等級與狀態，chip 表示標籤，反白印章表示官方旗標，外框表示證據等級，「!」表示本站提醒。可點的 chip 用 `--line-strong` 框，高度至少 24 px（觸控 44 px）。
3. accent 不做實心填色。選取狀態用 2 px 的 accent 內框。
4. 風險條各段之間留間隙，下方標「低／中／高／極高」；徽章一定寫出等級字。
5. 新增 Python 對比檢查（visual-9），每次測試都驗證色票，免得之後的改動悄悄退回不合格。

## 否決

- 官方旗標用實心琥珀底（對比 2.14:1，也會和警示撞色）。
- 任何 accent 實心填色，包括 a11y-6 的原案。
- 分數與評等 pill 繼續用漲跌色（即使是淡底）。
- 「外資買超前 15」、名次 ↑↓、13F 加減碼等標籤繼續用紅綠。
- 保留四種色相的風險色。
- 底部導覽列（另做一個重複的 nav）；手機頁首戳記用 46 px 補丁。
- 手機清單模式把表格列改成 `display:block`（會失去表格語意）。
