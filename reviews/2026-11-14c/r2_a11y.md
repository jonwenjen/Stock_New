## 2. 回答別隊問我們的問題
- **視覺 Q1（整卡 `<a>` 或只有標題）：** 只讓標題可點，因為 `<a>` 裡不能放星號按鈕。股名放 `h3 > a.pick-link`，`::after{inset:0}` 讓整卡可點；星號是獨立 `<button aria-pressed>`（`z-index:1`）；焦點用 `.pick:has(.pick-link:focus-visible){outline:2px solid var(--accent);outline-offset:2px}`，hover 只改邊框。
- **視覺 Q3（法人買賣超用紅綠）：** 同意，金額與張數屬實際成交，但必帶 ±、只上數字不做底色；名次標籤與議員、13F 的「買進／賣出」（延遲揭露）改中性加文字。
- **IA Q3：**
  1. **地標：** 不新增；現有 `<nav id="groups" aria-label="主要分類">` 在 560 px 以下用 CSS 改成底部列，DOM 不動，仍是兩個地標、Tab 順序不變。
  2. **`inert`：** Chrome／Edge 102、Safari 15.5、Firefox 112 起支援；舊瀏覽器退回現況，Esc 與焦點還原照常。
  3. **`--line` 1.30:1：** 違反 1.4.11（輸入框底色同面板，外框是唯一線索），改用 `--line-strong`。

## 3. 衝突與折衷

### 3.1 共用色票：以視覺隊第 4 節為基底
**接受：** `--rise／--fall` #cc3924／#007d68（深 #ef6447／#2fb3a3）、`--ink-3` #676f7d、`--warn` #986300／`--warn-soft` #fdf3dc、`--surface-2` #f7f8fa、`--line-strong` #848d9b／#626c7c、紫色明度階風險色與 `--rk-ink／-on／-line`、證據外框、MA 三色、刪除漲跌 soft 底、保留 `--up/--down` 間接層。

**撤回：** a11y-1 我們自己的色值（#c62f2f、#08775a、#636b78、#875800、#7f8998 等），以及 `--on-accent`。

**修正：**
1. 風險條各段之間留 1 px `--surface` 間隙，下方加「低／中／高／極高」，標記保留 `box-shadow:0 0 0 2px var(--surface-2)`。
2. 官方旗標用 visual-3 的反白印章，否決 IA P-2 的 rk2 底色。
3. accent 不做實心填色（rk3 對 accent 綠色盲 ΔE 1.0），撤回 a11y-6 的實心分段鈕，改 `.seg button[aria-pressed="true"]{background:var(--surface);color:var(--ink);box-shadow:inset 0 0 0 2px var(--accent)}`（對 surface-2 6.43／6.74）。
4. K 棒預設空心陽線；MA60 加 `lineStyle:3`，MA120 照 visual-6 用虛線。
5. 證據等級不用實心底，避免和官方旗標撞型。
6. 底部導覽字級用 13 px（依 visual-7），不用 12 px。
7. visual-9 要和換色同時上線。

### 3.2 底部導覽列（ia-1）
- 焦點不被遮住（2.4.11）：`html{scroll-padding-block:calc(var(--mast-h) + 8px) calc(56px + env(safe-area-inset-bottom))}`。
- 輸入時讓位：`body:has(input:focus, select:focus) #groups{display:none}`，免得蓋住鍵盤上方的輸入框。
- 短標籤都是全名的一部分，加全名 `aria-label` 仍符合 2.5.3；每鍵高 ≥ 48 px，沿用 `aria-current="page"`。

### 3.3 `inert`
抽屜開啟時對 `body > header, main, footer` 設 `inert`（底部列在 header 內，一併鎖住），關閉時解除並還原焦點，不必自寫 Tab 循環；原生 `<dialog>` 亦可。

### 3.4 固定首欄與螢幕閱讀器
- `position:sticky` 只影響畫面；對讀屏而言，等價做法是股名格改 `<th scope="row">`，橫向移動時會報出股名。
- 焦點格可能被固定欄蓋住：`.tbl-wrap{scroll-padding-inline-start:<首欄寬>}`，固定欄內連結 `outline-offset:-2px`。
- 清單模式不要對 `tr` 設 `display:block`（Safari／VoiceOver 會失去表格語意），改產生 `<ul>`。

### 3.5 精選頁的順序（視覺 Q2）
手機上組合風險加預算共 1,684 px，壓縮後仍超過一屏。採 IA 順序（卡片在前），卡片上方保留一行誠實摘要，如「β 0.68・一個月 95% 虧損界線 −12%・部位預算 ▸」。
