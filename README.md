# 週三選股雷達

每週三由 Claude 自動更新的台股＋美股研究儀表板：外資與融資動向、名人／議員／董監持股、財報指標、
ETF、基金績效評估、Podcast 熱議與分析、未來一週／一月／一季趨勢預測，以及精選 20 檔個股。純靜態網站，放在
GitHub Pages 即可，不需要伺服器，也不使用付費 API。

> 本專案產出的分數、機率與價位都是模型推估，**不是投資建議**。

## 更新方式

每週三由 Claude 的排程工作在雲端執行，使用 Claude 訂閱額度，不經 GitHub Actions、不呼叫付費 API：

1. 依 `WEEKLY_UPDATE.md` 抓取資料並計算分數（`python -m pipeline.build`）
2. 由當次執行的 Claude 根據同一批數據撰寫「AI 觀點」「Podcast 話題解讀」「ETF 觀察」「基金觀察」，
   寫入 `docs/data/ai.json`，並以 `python -m pipeline.check_ai` 檢查資料日期與結構
3. 直接提交並推送到 `main`

排程每週三台北時間 21:37 喚醒一個已掛載本 repo 的專用工作階段「週三選股雷達 每週更新」。
可在 Claude Code（claude.ai/code）查看每次執行的過程與回報，並在排程工作清單中暫停或手動觸發。
要改更新內容或撰寫規則，編輯 `WEEKLY_UPDATE.md` 即可，下次執行就會生效。

## 啟用 GitHub Pages

repo 的 Settings → Pages → Source 選 *Deploy from a branch*，分支選 `main`、資料夾選 `/docs`。

## 評分與預測方法

每檔股票計算四類因子（聲量只顯示、不計分），各自壓縮到 −1 至 +1：

- **技術面**：一個慢速分數（趨勢、20／60／120 日動能、一年區間位置），換算成同市場內的排名；台股再和
  「距 52 週高點」的排名各占一半。RSI、MACD、5 日報酬只當描述文字，不計分（審查回測顯示它們沒有預測力）
- **籌碼**：台股看外資與投信買賣超占成交量比重、外資連續買賣天數、融資變化；美股看議員淨買賣與 13F 增減
- **基本面**：台股看月營收年增、本益比、殖利率、淨值比、EPS、營收動能；美股看 EPS 與營收年增、本益比
- **聲量**：近兩週 Podcast 提及次數（只顯示、不計分；過熱時列為風險）

| 因子 | 台股 | 美股 |
|---|---|---|
| 技術面 | 60% | 80% |
| 籌碼面 | 25% | 5% |
| 基本面 | 15% | 15% |

一週、一月、一季用同一個分數，差別只在價格區間的寬度（現價 ± 一個標準差）。籌碼與基本面沒有歷史快照可回測，
權重先放低；缺資料的因子會被剔除並重新分配權重。

**網站不顯示個股的「上漲機率」。** 個股會不會漲大半取決於大盤，分數只能比較股票之間的強弱。顯示的是
**同市場排名**，以及**跑贏同市場中位數的機率**＝50% ＋ 斜率 × 排名分數。斜率每次建置用過去約三年的資料重估
（只在同一天的股票之間比較，大盤上漲不會被當成模型的功勞），並把資料切成五段逐段往前驗證；樣本外沒有勝過
「一律 50%」的市場一律顯示 50%。目前台股一週與一月有微弱優勢（約 47%–55%），美股沒有，標示「無可驗證優勢」。
指數顯示的是近 5 年的歷史上漲比率。

**精選規則**：依排名挑台股 12 檔、美股 8 檔；處置股不選；上週的精選若排名仍在台股前 30、美股前 20 就續留
（審查模擬顯示舊版每週換掉近六成，交易成本吃掉一半優勢）；同產業最多 3 檔；與已入選兩檔以上近 60 日相關係數
0.5 以上的跳過。精選頁的「部位預算」把各檔部位上限縮放到你打算投入的資金。

每檔另外顯示兩個輔助讀數：**籌碼分**（每天更新的外資、投信、融資，只有台股）與**基本面分**（財報與申報持股）。
停損以 ATR 的倍數設定，部位上限＝1% 資金 ÷ 停損距離，波動大的股票自動得到較小的部位。

**價格資料**：依證交所「除權除息計算結果表」把除權息前的價格等比例還原；自動刪除週末與休市日的 K 棒、
超過漲跌幅又回到原價的錯誤資料，台股超過 10.5% 且未回來的跳動視為未公告的斷層並接續。每次處理的內容列在
「方法與來源」的資料品質報告。

網站的「方法與來源」分頁會顯示技術面分數的回測：過去約三年每 5 個交易日計算一次分數，
比較高分組與低分組之後的實際報酬。

## 市場安全與預測驗證

「市場安全」分頁回答五個問題：現在大盤是否安全、哪些股票正在累積上漲動能、未來 5／20／60 日上漲機率、
哪些股票可能轉弱、過去的預測準不準。

- **風險分數**：趨勢與週期 20%、廣度 15%、國際連動 15%，外資現貨、外資期貨、融資槓桿、波動率、信用利差、
  美元流動性（Fed 淨流動性 13 週變化）各 10%；OFR 金融壓力指數與波動率、信用利差重疊，只顯示不計分；每項由「安全值」到「危險值」線性換算成 0–100。頁面同時用可回溯的項目重算歷史分數，
  列出各風險等級之後的指數表現。
- **市場週期**：依加權指數與季線、年線的位置分成五個階段，連續 3 日成立才算轉變。
- **預測準確度**：每次建置把所有個股與指數的預測存入 `docs/data/history/forecasts.json`，期間走完後自動比對
  （方向命中率、Brier 分數、偏多與偏空組的實際報酬）；另有技術面分數的三年校準表。
- **風險警報**：固定規則，每次更新自動檢查；`docs/data/history/market.json` 保存每次的分數以判斷變化。

台灣景氣領先指標（國發會）目前無法以程式取得（網站擋下自動化存取），所以沒有納入；TWGEX 的 GEX 與 TWVIX
需要逐筆選擇權資料，本站以選擇權未平倉分布、Put/Call 比與 VIX 期限結構代替。

## 已知限制

- **不是即時資料**：每週更新一次。「天」區間顯示更新當下最近一個交易日的分時走勢；
  台股分時依賴 Yahoo，取不到時改顯示最近 5 根日 K。
- **台股歷史深度**：證交所限制請求頻率，程式以每 6 秒一次的節奏存取，被拒絕時暫停並留待下次；
  冷啟動時每次執行最多補 120 個交易日。Yahoo 可用時會一次補上 10 年日線（會先驗證確實是日線）。
  初始資料約有 190 個交易日，之後每週自動加深。
- **融資維持率是估算值**：證交所只公布各股融資張數與全市場融資金額，本站以每日收盤價估算擔保品市值再相除，
  與券商逐戶計算的數字會有出入。個股的維持率更粗略：假設融資餘額增加當天以收盤價買進、逐日推估平均成本，
  每天校正到加總等於大盤維持率，並把低於 130% 的部位視為已被追繳；只適合找出壓力較大的個股。
- **領先指標只供判讀**：卡片上的偏多／偏空是市場常見的解讀，尚未用本站資料驗證，所以不計入任何分數；
  投信首買、合約負債季增、個股融資維持率同樣只列為多空理由。站上均線的廣度以觀察名單計算，漲跌家數才是全市場（上市）。
- **選擇權只有未平倉分布**：沒有計算造市者 Gamma 曝險（需要各履約價的隱含波動率並假設買賣方身分）；
  期交所開放資料為前一交易日。交易所不公布投信對個股的持股比例，所以沒有「投信持股過高」的警戒。
- **合約負債只對有預收款習慣的產業有意義**，季報公布後才更新。
- **申報有時間差**：議員交易最慢 45 天後才申報；13F 是季末持股、季後 45 天內公布。
- **Podcast 只分析節目標題與簡介**，沒有轉錄音訊；業配內容可能造成誤判。
- **回測有倖存者偏差**（樣本是現在的熱門股），且只涵蓋技術面因子。
- 台灣民意代表的持股沒有機器可讀的交易申報，因此「議員」部分只涵蓋美國國會。
- ETF 沒有個別財報，分數只看價格與（台股的）法人買賣超；上櫃 ETF（多數債券 ETF）不在名單內。
- 上櫃股只納入成交金額前 30 檔；上櫃股的除權息還原從 2026 年 11 月起逐週累積，董監持股與借券資料只有上市股。
- 期交所的散戶小台、十大交易人、基差、Put/Call 與外資選擇權部位回補了約一年，之後每週接續。
- 基金的風險指標由淨值計算，淨值不含配息還原，配息級別的回檔會被高估（名單因此優先選累積級別）；
  基金名單是人工挑選的常見基金，不是全市場排名。
