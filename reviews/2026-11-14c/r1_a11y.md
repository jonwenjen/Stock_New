# 第一輪：可及性、行動裝置與效能（a11y 隊）

對象：live 662c814（HEAD 已到 087aaf2，故以 `git archive` 重測；兩版 CSS 與 HTML 相同）。本機 gzip 伺服（同 GitHub Pages），Playwright 量測桌面 1280×900、手機 390×844，淺深色與兩種漲跌慣例。證據在 `/tmp/claude-0/-home-user-Stock-New/6f855783-f89b-564b-bdfb-2f7f4ef27d28/scratchpad/a11y/`（下稱 `A/`，live 結果在 `A/out662/`）。

## 1. 一句話結論

焦點框、語言屬性、減少動態都已做對，但淺色模式有 1,370 處文字不到 AA（主因是綠色數字只有 4.07:1）、表頭不能用鍵盤排序、抽屜宣稱 modal 卻不鎖焦點、手機首次載入 CLS 0.93。十項修正多為 S 成本的 CSS 與屬性修改，建議先做色票、鍵盤與抽屜、首次載入三件。

## 3. 提案（依優先順序）

**a11y-1 色票對比（只改 token）｜P0｜S**
- 為什麼：漲跌數字是散戶最常看的資訊，綠字 4.07:1 在戶外或低亮度手機上很吃力。
- 改法：style.css 淺色改 `--rise:#c62f2f`、`--fall:#08775a`、`--ink-3:#636b78`、`--warn:#875800`、`--rk1:#5d6470`；深色改 `--rise:#f06b6b`、`--fall:#2fb38c`。新增 `--rk3-ink`（淺 #fff、深 #1a1024），`.pill.rk3{color:var(--rk3-ink)}`。`.pill.s2/.s-2` 改成 soft 底加 `border-color:currentColor`，不再用白字實心（也符合限制 3）。數值見 §4，全部 ≥ 4.5，兩種慣例同時過關。
- 影響：全站數字、pill、chip、K 棒。

**a11y-2 表頭可用鍵盤排序、列改成連結｜P0｜S–M**
- 為什麼：鍵盤與讀屏使用者無法排序，走完財報指標要按 322 次 Tab。
- 改法：`table()` 的 th 內放 `<button type="button" class="sort">`，`aria-sort` 留在 th；拿掉 `tr` 的 `tabindex`，股名欄改 `<a href="#{view}?s={sym}">`（抽屜由網址驅動，可新分頁、可分享），`tr` 的 click 只給滑鼠；散佈圖點 `tabindex="-1" aria-hidden="true"`。
- 影響：所有表格；財報指標停留點約從 322 降到 218。

**a11y-3 抽屜成為真正的 modal｜P0｜S**
- 為什麼：按 Tab 會跑進被遮住的背景，使用者找不到焦點。
- 改法：`showDrawer` 時對 `body > header, main, footer` 設 `inert = true`，`hideDrawer` 時解除；抽屜標題改 `<h2 id="drawer-title">`＋`aria-labelledby`。也可改用原生 `<dialog>`＋`showModal()`。
- 影響：個股、ETF、基金三種抽屜。

**a11y-4 首次載入不跳動、少載資料｜P0（CLS）／P1｜S**
- 為什麼：手機第一次打開，2.6 秒時整頁往下跳。
- 改法：`main{min-height:calc(100svh - var(--mast-h,140px))}`＋`@media (max-width:560px){.stamp{flex:1 0 100%;min-height:46px;align-content:flex-start}}`，live 實測 CLS 0.93 → **0**。接著：knowledge.js 進 `#learn` 才載入、universe.json 用到才載入（首屏少約 100 KB gzip，估計快 0.5 s）；其餘 JSON 加 preload（實測 0–180 ms，收益小）；字型自架 woff2 或至少 preconnect；拿掉 `touchstart` 預抓。

**a11y-5 焦點不被遮住、跳過連結、頁面標題｜P1｜S**
- 為什麼：倒退 Tab 時焦點藏在頁首下；每頁都要先按過 11 個導覽停留點；書籤全部同名。
- 改法：`html{scroll-padding-top:calc(var(--mast-h,140px) + 8px)}`。`<body>` 第一個元素放 `<a class="skip" href="#app">跳到主要內容</a>`（`.skip{position:absolute;left:-999px}`、`.skip:focus{left:16px;top:8px;z-index:30}`，`#app` 加 `tabindex="-1"`）。`route()` 設 `document.title = 分頁名 + "｜週三選股雷達"`；`head()` 標題改成 `h1`，外觀不變。

**a11y-6 狀態不只靠色相、表單外框｜P1｜S**
- 為什麼：分段按鈕與子分頁目前選的是哪個，色弱或 Windows 使用者看不出來。
- 改法（第二輪改為內框，見 r2）：`.seg button[aria-pressed="true"]{background:var(--surface);color:var(--ink);box-shadow:inset 0 0 0 2px var(--accent)}`；`.subtabs a[aria-current="page"]{box-shadow:inset 0 0 0 1px var(--accent)}`；表單邊框改 `--line-strong`；`@media (max-width:560px){select,input{font-size:16px}}`。

**a11y-7 價格色歸還給價格｜P1｜S**
- 為什麼：紅色同時代表上漲、「優異」與看多分數，弱訊號容易被讀成強訊號；切換慣例後「成功」還會變紅。
- 改法：`gradePill` 改中性強度 chip；`REGIME` 改 `rk0／rk2／rk1`；市場週期改 `s0`＋文字；`BO` 假突破 `rk2`、真突破 `s0`；警報 `li.alert-i::before{content:"!";color:var(--rk2)}`；`.dot.ok{color:var(--ink-2)}`、`.dot.bad{color:var(--rk2)}`；`meter()` 與分數不用漲跌色（保留正負號）；`.why` ▲ `--ink-2`、▼ `--rk2`；停損線 `--rk2`、+1σ `--ink-3`。買賣超屬漲跌語意，維持。

**a11y-8 K 棒空心、均線換線型｜P1｜S**
- 為什麼：約 8% 的男性分不出紅綠 K 棒，也分不出 MA20 與 MA120。
- 改法：app.js:323 `upColor:css("--surface")`，上漲空心（框與影線 `--up`）、下跌實心，圖例註明；MA60 `lineStyle:2`、MA120 `lineStyle:1`，`--ma3` 改 `#3f4652`／`#c3cad5`（色盲下對 MA20 ΔE76 50–59）。

**a11y-9 精選卡去巢狀｜P1｜M**
- 為什麼：讀屏把每張卡念成 341 字的按鈕，星號只念「☆」。
- 改法：app.js:869 改成 `article.pick`，股名放進 `h3 > a.pick-link[href="#picks?s=SYM"]`；`.pick{position:relative}` 加 `.pick-link::after{content:"";position:absolute;inset:0}`，整張卡仍可點。星號改成真正的 `<button class="star" aria-pressed aria-label="加入自選：麗臺">`，設 `position:relative;z-index:1`，刪掉 `role`、`tabindex` 與自訂 keydown。

**a11y-10 手機導覽、寬表、觸控目標｜P1｜M**
- 為什麼：第五組看不到；寬表橫捲後不知道是哪一檔；小目標容易誤觸。
- 改法：`@media (max-width:560px){.tabs{display:grid;grid-template-columns:repeat(5,1fr)}}`＋兩字短標籤（總覽／選股／籌碼／配置／知識）；子分頁加 `mask-image` 漸隱提示可捲。寬表 `th:first-child,td:first-child{position:sticky;left:0;background:var(--surface);z-index:1}`，刪掉無效的 `th{top:0}`。目標：`.help::after{content:"";position:absolute;inset:-8px}`、`@media (pointer:coarse){.close,.star,button.chip,.linkish,.seg button{min-height:44px}}`。精選頁手機版卡片排在組合風險與預算之前。

## 5. 待辦 UI 項目的意見（建議順序）

1. **product-7 可及性：做，第一順位。** 即 a11y-1、-2、-3、-5、-6、-9（配色另見 -7、-8）；順序：色票 → 表頭與列連結 → 抽屜 inert → 卡片去巢狀。
2. **product-10：延後載入現在做（a11y-4），PWA 放最後。** `max-age=600` 已讓 10 分鐘內重整只要 0.44 s，SW 多的只有離線與少一輪 304。要做時：`data/*.json` network-first、離線回退並標「離線：資料日 X」；靜態檔 cache-first，快取名綁 `data_date`。
3. **product-3 手機首屏與導覽：做。** 形式見 a11y-10：第一層改成五欄短標籤、不橫捲；頁首資料列縮成一行；精選頁讓卡片先出現。
4. **product-8 清單模式與欄組：做。** 先固定第一欄（S），再加「價格／籌碼／基本面」欄組切換（seg）；手機清單模式每列只放 3 個關鍵數字；CSV 仍然匯出全部欄位。
5. **product-9：分享網址先做（S–M），比較頁之後（M–L）。** 篩選與排序寫進 hash（例如 `#fund?m=TW&sort=pe`），上一頁鍵也能用。比較圖用線型加直接標籤區分 2–4 檔，並附等值表格。
6. **product-6 iCal／Atom：補連結即可（S）。** HEAD 00bca9a 已產生 `calendar.ics`、`feed.xml`，但頁面沒有連結（grep 0 次）。補 `<link rel="alternate" type="application/atom+xml" href="feed.xml">` 與卡片上的可見連結。

## 6. 給其他兩隊的問題

1. 視覺隊：淺色漲跌色加深到 #c62f2f／#08775a、取消白字實心 pill，你們能接受嗎？若偏好別的色相，能否保證在 `--bg #f3f5f8` 上 ≥ 4.5:1？
2. 視覺隊：證據等級用不帶色相的強度樣式（A 實心、B 實框、C 虛框、D 點框），是否符合你們的系統？若要專屬色相，必須避開紅綠、風險四色與 accent。
3. 資訊架構隊：手機第一層能否改成兩字短標籤、五欄全部露出？精選頁的卡片能否排在組合風險與預算面板之前？
