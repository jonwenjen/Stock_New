# 「投資方法與紀律」的數字來源

`docs/knowledge.js` 的「投資方法與紀律」一節引用的數字，由這三支程式從 `docs/data/charts/` 的 TWII、0050_TW、SPY、00631L_TW 計算（2026-11-20）：

- `disc.py`：持有期間上漲比例、最大回檔與修復時間、錯過最好的 N 天、距高點 −10%／−20% 買進一年後、一次投入對比 12 個月定期定額、小勝率的二項分配。
- `disc2.py`：00631L 與加權指數、0050 的最大回檔、目前距高點、盤整期（0050 半年漲跌 ±3% 以內）的表現。
- `disc3.py`：每次第一次跌破 −20% 之後再跌多少、一年後漲跌、回到前高的日期。

執行：`python3 reviews/2026-11-20/discipline/disc.py`。資料會隨每次更新延長，數字會略有變動；網站上的文字標明了計算日期。
