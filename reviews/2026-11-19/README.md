# 2026-11-19 「漲跌預警」改版建議審查

使用者轉來一份 `#alerts` 改版建議。每項先在本站資料上檢驗可行性與效果（回測腳本：3 年價格檔、每週一期，用今天的名單，數字只是上限；
兩個市場共 24 個檢定，即使全部無效也預期約 1 個 |t| ≥ 2），再決定做不做。

## 判定
| 建議 | 判定 | 理由 |
|---|---|---|
| 一-1 訊號落後、改事件型 | 採納 | 頁面改成四類事件，靜態前後 12 名移除（排名本來就在精選與財報指標頁） |
| 一-2 弱勢原因混雜 | 採納 | 「基本面與籌碼背離」獨立一類 |
| 一-3 台美混排 | 採納 | 加全部／台股／美股切換（網址可分享） |
| 二-1 排名動能 | 採納 | 和上一個週次快照比；台股升 20 名、美股升 10 名，或剛進前 15／剛跌出前 30。台股排名大升之後略強（t 2.0），頁面照實寫 |
| 二-2 ATR 乖離與 52 週回撤 | 修改後採納 | 列入「波動與乖離」，但**不叫追高風險**：台股乖離大的股票之後平均反而較強、只是回檔較深；52 週回撤已在抽屜（距 52 週高點） |
| 二-3 型態新鮮度 | 部分採納 | 只保留「3 日內站上／跌破季線」作為描述性事件；月線交叉與 MACD 翻轉沒有任何差異又每週觸發很多檔，不列（避免警報疲乏） |
| 二-4 美股類籌碼（RVOL、CMF） | 不採納（作為籌碼） | 美股爆量之後沒有可測差異、方向還和台股相反；「機構吸籌／派發」是事後才分得出的說法（同 2026-11-14d 的 C10d）。爆量長紅／長黑只當作「波動」事件列出，兩個市場都適用 |
| 二-5 基本面 × 籌碼背離 | 採納（只描述） | 個股籌碼歷史約 100 日，無法檢驗，頁面註明未驗證 |
| 三-1 四類事件與連續在榜週數 | 採納 | 每週快照記錄事件類別，計算連續週數 |
| 三-2 ★ 自選股預警置頂 | 採納 | 自選清單中有任何事件的股票列在最上面 |
| 三-3 弱勢表「部位上限」語意 | 採納 | 改為「距季線 %」與「停損參考」 |
| 三-4 每日更新 | 不採納 | 網站每週一、三、五清晨重建（訂閱額度排程、證交所限流）；同一週內的排名變化在下一週才算進來，頁面已註明 |
| 三-5 錯字 | 部分不成立 | 導覽列原本就是「輿情與知識」；「價格經清理還原」容易誤讀，改為「價格已清理異常並還原除權息」 |
