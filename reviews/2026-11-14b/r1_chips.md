# R1：台股籌碼與衍生品實戰隊（chips）

審查對象：commit 63a1496 的 docs/ 與 pipeline/，資料日 2026-11-13。方法：讀相關 view 與警示程式碼、本機資料計算、14 次官方請求（文末）；為省共用額度未截圖。工作腳本放在 scratchpad 的 `chips/`（a1–a3.py、net1/net2.py、parse1.py，原始回應在 `chips/dl/`）。

## 1. 一句話結論

外資台指期淨空單要先扣掉投信（槓桿 ETF）的多單，再拿來判讀。11/13 外資 −100,870 口，幾乎就是投信 +99,923 口的鏡像，三大法人合計只有 −3,718 口。網站卻把它當成「一年最偏空」計入風險分數（98.4 分）並發出警示。同時要先修好除權息因子重複套用（119 檔台股中 74 檔受影響），否則任何新的籌碼或填息顯示都建立在錯的價格上。

## 2. 發現的錯誤或資料問題

### E1【P0】除權息因子重複套用，價格序列被錯誤還原兩次
- 原因：`prices.py:324` 用 `key = f"{d}:{f:.6f}"` 判斷是否已套用。同一個除息日以兩種精度進來：本期 TWT49U 算出 `0.970723`，舊的 key 是 `0.970700`。字串不同，所以又乘了一次。
- 證據：0056 在 2026-10-21 的 charts 收盤是 55.36，`.cache/twse_days` 的原始收盤是 58.75，比值 0.9423 = 0.970723 × 0.9707，表示同一筆股利乘了兩次。0056 的 `applied` 同時有 `2026-10-22:0.970723` 與 `2026-10-22:0.970700`。
- 範圍：117 個 chart 檔，其中觀察名單台股 74/119 檔、ETF 12 檔，第一筆重複都落在最近 250 個交易日內。重複日期之前的報酬被高估，各檔幅度如下：

  | 代號 | 高估幅度 |
  |---|---|
  | 6669 緯穎 | +207%（9/02 的 0.3353 減資或分割因子乘了兩次） |
  | 6446 | +11% |
  | 2603 | +7.8% |
  | 2885 元大金（精選） | +7.1% |
  | 2471 資通（精選） | +6.8% |
  | 00881 | +9.1% |
  | 00919 | +7.0% |
  | 00929 | +6.4% |
  | 0056 | +5.9% |

- 影響：距 52 週高點、一年報酬與回檔、ETF 頁績效、回測的近期段，以及我在下面算的填息統計（重複事件會變成「當天就填息」的假象）。

### E2【P0】十大交易人卡片：數值是近月，走勢與百分位是全月份
- `leading.py large_traders()` 找的是 `SettlementMonth == "999999"`。期交所 openapi 的全月份代碼其實是 `999912`（已驗證 11/13 的列：202611、666666、999912），所以程式退回近月 202611。
- 卡片數值：(91,547 − 71,991) / 111,151 = **+17.6%**。
- 歷史 CSV 的全月份：(102,920 − 88,315) / 135,553 = **+10.77%**。
- 同一天兩個來源一直對不上：11/10 0.1184 對 0.0726，11/12 0.1609 對 0.1015，11/13 0.1759 對 0.1077。卡片上「高於一年 100% 的日子」是拿 0.176 去比最大值只有 0.108 的序列，是定義不一致造成的假象。

### E3【P0】「外資期貨」風險分項與警示，量到的是投信多單的鏡像
- 期交所 openapi 11/13 的臺股期貨未平倉：

  | 身分 | 多單 | 空單 | 淨額 |
  |---|---|---|---|
  | 投信 | 103,019 | 3,096 | **+99,923** |
  | 外資 | | | −100,870 |
  | 自營商 | | | −2,771 |
  | 三大法人合計 | | | **−3,718** |

- 十大交易人的多方 102,920 口（其中特定法人 101,485）幾乎等於投信的 103,019 口多單，也就是槓桿 ETF 的機械性部位。卡片說「大戶部位通常比散戶有參考性」，其實讀到的是 ETF 的槓桿需求。
- 外資淨未平倉與加權指數水位的相關係數是 **−0.907**（267 日，`tw_futures.json`）。一年間外資空單從 −23,701 口增加到 −100,870 口，指數從 27,212 漲到 43,675。
- 結果：最近 60 天裡有 32 天的一年百分位 ≤10%。`market.json` 的 futures 分項是 98.4 分（權重 10），警示「外資台指期淨空單在一年高檔」幾乎常駐。改看 20 日變化，目前位於一年的第 19 百分位，偏空但不極端。
- 修正不需要新請求：`market.parse_futures_csv()` 每週下載的 TXF CSV 本來就有投信那一列，只是只取了外資。

### E4【P1】上櫃股的籌碼欄位與上市股不一致
universe.json 有 90 檔上市、29 檔上櫃（brief 寫 30 檔）。各欄位覆蓋率（上市／上櫃）：

| 欄位 | 上市 | 上櫃 |
|---|---|---|
| margin_chg5 | 100% | 0% |
| maint_est | 99% | 0% |
| qfii_chg20 | 100% | 0% |
| insider_pledge | 100% | 0% |
| cl_qoq | 68% | 0% |

原因：
- `update_maintenance()` 的 5 日前融資表只有證交所資料，所以 `chips_tw()` 的融資加減分（±0.05～0.15）對上櫃股不存在。
- `trust_first_buys()` 在上櫃法人資料併入之前就算完了，上櫃股永遠不會出現「投信首買」。
- `top_flow()`、`margin_moves`、`margin_risk` 都用只有上市的 `quotes`／`spot_close` 過濾，徽章也寫死 `code + ".TW"`。上櫃股的徽章只有 注意股 13、動能累積 4、營收剛轉強 1，上市股則有外資、投信、借券、斷頭等十多種。
- `update_qfii()` 只把上市代號寫入存檔：`tw_qfii.json` 11/13 存了上市 90 檔、上櫃 0 檔。app.js 寫「上櫃股的 20 日變化要累積幾週存檔後才會出現」，按目前的程式碼永遠不會出現。
- 上櫃的「可能處置」來源 `tpex_trading_warning_note` 沒有使用（已驗證可取得，5 筆）。例：**聯一光 3441 被列為「115年11月10日至11月13日連續四次」**，網站只標「注意股」。`tpex.py:128` 把注意次數寫死為 1。
- 上櫃借券 `tpex_margin_sbl` 也沒有使用（已驗證，935 檔，涵蓋全部 29 檔上櫃觀察股）。
- 小問題：`tpex.py:19` 的 `setdefault("www.tpex.org.tw", 3.0)` 不會覆蓋 `http.py` 既有的 1.0，所以上櫃的實際節流是每秒 1 次，跟註解的意圖不同。

### E5【P1】上市注意股幾乎是空的
觀察名單中，上市 0/90 檔有注意標記，上櫃有 13/29 檔。旗標是 2026-11-14（星期六）抓的，而證交所 `announcement/notice` 只提供當日快照，所以週三建置也只看得到週三一天。我測試的區間查詢 `rwd/zh/announcement/notice?startDate&endDate` 回了 307，**未驗證**。目前上市股能看到的處置前哨只有 notetrans（冠西電 2466「連續二次」）。

### E6【P1】個股法人歷史只保留 30 天，籌碼權重 .25 永遠無法驗證
`build.py stock_flows()` 只保留 `sorted(store)[-(n+10):]`，也就是 30 天。我用現有 20 天做了一個很小的樣本：11 個重疊日期、119 檔，算下一週報酬的 IC。外資 f5 是 +0.21，投信 t5 是 **−0.11**，而分數假設投信買超加分（+0.20·tanh(t5/0.25)）。樣本太小，不能下結論，但說明這組權重目前沒有根據，而驗證它需要的資料正被丟掉。

### E7【P2】衍生品卡片的固定門檻太常觸發，一年資料看不出區分力
以下用 `tw_derivs.json` 的 259 天，比較各色調之後加權指數的 5 日與 20 日報酬：

| 卡片 | 觸發天數 | 之後 5 日 | 之後 20 日 |
|---|---|---|---|
| P/C「偏多」（≥1.1） | 156/259（60%） | +1.14% | +5.36% |
| P/C「偏空」（<0.9） | 47 | +1.96%（方向相反） | −0.38% |
| 散戶小台「偏空」（≥20%） | 94/240（39%） | +1.48%（中性 +1.34%） | |
| 基差 | | 看不出差異 | |

- P/C 有結算週期的鋸齒：週三（週選結算）單日平均 **+14.2 個百分點**（n=44），其他日子 −3.4。週間平均：週三 1.28、週四 1.13。
- 近一個月 P/C 一直在 0.40–0.69，遠低於一年均值約 1.2。
- 結算日本身不會放大加權指數的波動。五年資料的平均絕對報酬：月結算日 0.90%、其他週三 1.04%、一般日 0.96%、月結算隔天 0.99%。行事曆沒有列週五週選結算。

## 3. 提案（依優先排序）

### 1. 除權息因子去重並重建價格【修錯・P0・S】
- **放在哪裡**：`prices.sanitize()`，加一條測試：同一代號、同一日期只能有一個因子。
- **決策價值**：停損、52 週位置、ETF 績效，以及下面的填息統計都要靠它才可信。
- **精確定義**：key 改成只用 `{date}`。同一天的多個因子只取 TWT49U 的 6 位精度。已重複的序列，用 `applied` 的乘積反推，或用原始日表重建。
- **資料來源與可行性**：零新請求。
- **目前證據**：E1。
- **信心與主要風險**：信心高。風險是較舊的事件超出 `.cache` 範圍時，只能用因子反推。

### 2. 期貨籌碼改用「外資＋投信淨部位」，並修正十大交易人【修錯/改善・P0・S】
- **放在哪裡**：總覽的期貨卡片、市場安全的「外資期貨」分項、警示、外資法人頁的統計框。
- **決策價值**：散戶週三最常問「外資是不是在空台指」。現在的答案是被 ETF 槓桿需求扭曲的「一年最空」，會讓人在多頭回檔時過度減碼或放空。
- **精確定義**：
  - 每日臺股期貨等值淨未平倉＝TX＋MTX/4＋TMF/20，分別算外資、投信、自營。
  - 顯示「外資」「投信（多為槓桿 ETF）」「合計」三個數字。
  - 風險分項改用（外資＋投信）20 日變化在一年中的百分位，不用水位。
  - 十大交易人：`999912` 與 `999999` 都接受；卡片和歷史用同一個定義（全月份），並分列特定法人與非特定法人。
- **資料來源與可行性**：`futContractsDateDown`（TXF／MXF）原本每週就在下載，裡面已經有投信列，改解析即可，**每週 +0 請求**。TMF 每月窗口 +1 請求。一年回補一次約 13–26 個請求，可以分兩週做。openapi 的投信列**已驗證**。
- **目前證據**：E2、E3（投信 +99,923 對外資 −100,870；相關係數 −0.907；百分位 ≤10% 的日子占 32/60）。
- **信心與主要風險**：信心高。風險是投信部位也含部分避險型 ETF，解說要寫明「多為槓桿型 ETF 的機械部位」。

### 3. 個股當沖率＋「短線過熱」檢查（權重 0，只標示）【新指標・P0・S】
- **放在哪裡**：抽屜「關鍵數據」、精選卡片徽章「當沖 ≥60%」、融資融券頁新增「短線過熱」表（當沖率、融資使用率、券資比）。
- **決策價值**：當沖率高的強勢股，隔日開盤常有賣壓，也是官方注意股的條件之一。散戶週三看到它，就知道不在隔天開盤追價、要等量縮。
- **精確定義**：當沖率＝當日沖銷交易成交股數 ÷ 當日成交股數（分母用已快取的 MI_INDEX 日表）。顯示最新一日與 5 日平均。≥60% 標黃、≥70% 標紅。券資比只在融資 ≥2,000 張時顯示。
- **資料來源與可行性**：`https://www.twse.com.tw/rwd/zh/dayTrading/TWTB4U?date=YYYYMMDD&selectType=All&response=json`，**已驗證**：200，1,241 檔，另附全市場統計表。上一輪用 `exchangeReport/` 路徑才會拿到 307。**每週 +1 到 +5 請求**（6 秒節流下 +6 到 +35 秒）。上櫃 `tpex_intraday_trading_statistics` 只有全市場 10 列，**沒有個股**；上櫃個股以注意股文字中的當沖條件代替，www 版**未驗證**。
- **目前證據**：
  - 11/13 官方全市場當沖占成交股數 31.3%。
  - 觀察名單上市 88 檔的中位數是 54%：≥60% 有 36 檔，≥70% 有 8 檔。
  - **台股精選 10 檔（有資料）中有 5 檔 ≥60%**：麗臺 68%（第 1 名）、台玻 84%（第 3 名，5 日 +47%）、GIS-KY 76%、資通 73%、華經 69%。
  - TPEx 官方注意股文字已直接寫出當沖比率：富喬 68.2%、穩懋 65.2%、建榮 74.3%、金居 62.5%、華星光 61.1%。
- **信心與主要風險**：信心高。風險是預測力未驗證，所以從第一週開始存檔，權重維持 0，符合既有決議。

### 4. 上櫃籌碼補齊與處置前哨【改善・P1・M】
- **放在哪裡**：外資法人頁與融資融券頁的排行、徽章、抽屜。
- **決策價值**：上櫃中小型股最常被處置，也最常被散戶追。聯一光已「連續四次」注意，網站只標「注意股」。
- **精確定義**：
  - 改成在上櫃法人資料併入之後才算投信首買；`top_flow`／融資排行改用上市加上櫃合併的收盤價；徽章用 `meta` 的 symbol。
  - 存檔 `tw_qfii` 時也存上櫃。
  - 加入 `tpex_trading_warning_note` 作為 near_punish；從 notice 文字解析注意次數。
  - 融資 5 日變化改用週對週的 openapi 快照存檔。
  - 加入 `tpex_margin_sbl`。
  - 上櫃董監質押：`mopsfin_t187ap11_O`，**未驗證**。
- **資料來源與可行性**：warning_note 與 margin_sbl **已驗證**。每週 +2 請求，在 TPEx openapi 上，影響約 2 秒。
- **目前證據**：E4。
- **信心與主要風險**：信心高。

### 5. 保存個股籌碼歷史並回補一年【改善・P1・M】
- **放在哪裡**：`history/`，只存觀察名單約 150 檔；畫面不變。
- **決策價值**：籌碼權重 .25（以及投信的正負號）能不能用，取決於能不能回測。
- **精確定義**：T86 外資、投信、自營，加上融資與借券，逐日存觀察名單（約 3 MB／5 年）。T86 每次 build 回補 40 天，由新到舊。
- **資料來源與可行性**：T86 每天 1 請求，回補期間 **+40 請求／週（約 +4 分鐘）**，約 6 週完成。融資與借券的每日表 `.cache` 已有一部分。
- **目前證據**：E6（小樣本 IC：外資 +0.21，投信 −0.11）。
- **信心與主要風險**：信心中。風險是 T86 偶爾回 307（我這次就遇到）；`fetch_days` 已經會退避重排。

### 6. 衍生品卡片改用自身百分位，並標示結算週期【改善・P1・S】
- **放在哪裡**：總覽的衍生品卡片。
- **決策價值**：避免「偏多／偏空」色塊每兩天就亮一次，散戶照著翻多翻空。
- **精確定義**：
  - 色調只在一年百分位 ≤10% 或 ≥90% 時亮。
  - P/C 改用同週間的比較，或月合約 P/C（optwall 已經算出 58%），週三附註「週選結算日的跳動」。
  - 外資選擇權同時顯示口數與契約金額（CSV 第 15 欄，已驗證），以金額判斷方向。
  - 行事曆加入週五週選。
- **資料來源與可行性**：零新請求。
- **目前證據**：E7。
- **信心與主要風險**：信心中高。

### 7. 事件行事曆：ETF 換股、MSCI／FTSE 審核、投信季底作帳【新功能・P1・S】
- **放在哪裡**：總覽的兩週行事曆、個股抽屜徽章。
- **決策價值**：0050、0056、00878、00919、00929、00940 等大型 ETF 在已知日期尾盤大量買賣，被納入或刪除的個股當天常爆量。散戶要知道「那天的大量不是主力」，也不要在生效日前追即將被刪的股票。12 月是投信年底作帳月。
- **精確定義**：手動維護 `config/index_events.json`（日期、指數、ETF、來源網址、最後確認日），只放已公告的內容。若已知變更名單，在個股上加「ETF 調入／調出」徽章。
- **資料來源與可行性**：發行商與指數公司的公告，人工每月約 15 分鐘。TPEx 自家指數有成分股端點（`tphd_constituents` 等，在 swagger 中，**未驗證內容**）。
